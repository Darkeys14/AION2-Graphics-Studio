## AION 2 Graphics Studio 0.5.2

Исправлена проверка обновлений: вместо GitHub API используется перенаправление страницы последнего стабильного релиза. Это устраняет зависимость от общего лимита анонимных API-запросов. Версия и имя установщика проходят проверку формата, адреса фиксированы на официальном репозитории проекта, размер ограничен, SHA-256 сверяется по файлу контрольных сумм релиза.

Уведомление об авторских правах и статус лицензии из версии 0.5.1 сохранены.
