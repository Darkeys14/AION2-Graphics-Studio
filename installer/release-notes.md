## AION 2 Graphics Studio 0.3.0

Скачайте **AION2-Graphics-Studio-0.3.0-Setup.exe**. Версию 0.2 нужно обновить установщиком один раз: автообновление появилось только в 0.3.

### Новое

- Проверка сохранения записанных студией параметров после выхода из игры.
- Несколько именованных профилей из игры и локальные снимки конфигурации.
- Панель нагрузки CPU, GPU 3D и ОЗУ с историей замеров, без измерения FPS.
- Явное отложенное применение профиля или Engine.ini после закрытия игры и паузы сохранения; отмена задачи.
- Анализ DeviceSetting_V2.dat и сравнение снимков без редактирования файла.
- Автоматические обновления установленной версии со стабильных релизов GitHub: фоновая загрузка, SHA-256, установка при закрытии и перезапуск. Режим можно отключить; есть ручная проверка.

Профиль из игры применяет только 13 групп качества. Снимки Engine.ini и DAT сохраняются локально для сравнения и автоматически не восстанавливаются. Отложенная задача требует открытой студии и не возобновляется после её перезапуска. Portable и исходники не заменяются автообновлением.

### Проверки и ограничения

32 модульных теста и проверка создания 10 страниц интерфейса выполняются перед сборкой. GitHub Actions также проверяет установку, запуск и удаление. Проверка файлов не доказывает визуальный эффект команд. Влияние Engine.ini на рендер этой сборки AION 2 и FPS не подтверждено. Формат DAT не расшифрован; он не редактируется. Пользовательские данные остаются локальными и сохраняются после обновления и удаления студии.

Приложение не внедряется в процесс игры и не меняет античит. Установщик не подписан сертификатом издателя. SHA-256 подтверждает целостность загрузки, а не подлинность издателя.

Дополнительно приложены переносная версия и SHA256SUMS.txt. Исходники доступны в репозитории и стандартных архивах GitHub Source code.
