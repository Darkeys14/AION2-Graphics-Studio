## AION 2 Graphics Studio 0.5.0

Новая вкладка **«Во время игры»** наблюдает за GameUserSettings.ini и Engine.ini, показывает распознанные значения и журнал изменений. Обновление выполняется примерно раз в 2,5 секунды. Режим только читает файлы и не пишет в них.

Меняйте параметры, которые игра применяет сразу, через её собственное меню. Студия не отправляет игровые команды и не подключается к процессу. Изменения INI во время сессии отключены, потому что клиент может одновременно сохранять собственные настройки.

Также входит вкладка «PvP · расширенный» с профилем для массовых сцен, отдельным набором трёх параметров Engine.ini, точечной записью с проверенной копией и сравнением замеров PresentMon. Этот набор показал обнадёживающие результаты в повторных городских замерах, но эффект может меняться между сценами и сборками игры.

43 модульных теста и проверка 12 страниц интерфейса. GitHub Actions проверяет установку, помощник обновления, перезапуск и удаление с сохранением данных.

Студия читает только локальные конфиги, не внедряется в игру и не обходит античит. Наблюдаемые значения файлов не гарантируют, что движок применил их в текущем кадре. Настройки остаются локальными. Установщик не подписан сертификатом издателя.
